如何使用 Flag Icons

1. 引入 CSS

你可以直接使用本站在线托管的 CSS 文件（无需下载）：

HTML / CDN 
<link rel="stylesheet" href="https://flags.etoj.run.place/css/flag-icons.min.css" />

2. 在 HTML 中使用

在空 span 标签上添加 .fi 和 .fi-xx 类即可显示旗帜。将 xx 替换为对应的旗帜代码。

标准 4:3 格式 
<span class="fi fi-us"></span> 美国

3. 提示

  • 点击页面上任意旗帜即可复制其 HTML 代码
  • 本库仅提供 4:3 格式，不再支持 1:1 方形旗帜
  • 使用内置的搜索和筛选功能来查找特定旗帜
